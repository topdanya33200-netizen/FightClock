**Антирелог (режим PvP) для серверов на Paper и Folia.** Удар переводит обоих игроков в режим боя с таймером
на боссбаре. Пока он идёт, сбежать командами, телепортом, через портал, на элитрах или полётом нельзя, а выход
с сервера убивает игрока, и убийство засчитывается его противнику.

[English version](README.md)

## Возможности

- **Бой начинается от любого урона игрока:** удар, стрелы и трезубцы, кристаллы Энда и динамит, взрывные и
  оседающие зелья. Каждый вид можно отключить. Нападающий определяется через `DamageSource` Paper, поэтому в бой
  попадает именно тот, кто взорвал кристалл или выпустил стрелу.
- **Уважает плагины защиты.** Удары, которые отменили плагины регионов, команд или friendly fire, бой не начинают.
- **Таймер на экране:** боссбар с именем противника, который убывает, и таймер над хотбаром. Каждый новый удар
  запускает отсчёт заново.
- **Запрет команд** в режиме чёрного или белого списка. Алиасы и команды с префиксом вроде `/essentials:home`
  распознаются, обойти список ими не получится.
- **Никаких путей отхода:** в бою заблокированы телепорт командами, порталы в Незер и Энд, раскрытие элитр и
  `/fly`. Эндер-жемчуг и плоды хоруса работают как обычно.
- **Увеличенные кулдауны предметов** в бою, например 15 секунд на эндер-жемчуг и 60 на зачарованное золотое яблоко.
- **Выход из боя — смерть.** Настоящая: вещи выпадают, тотем не спасает, а убийство засчитывается противнику
  в статистике и на скорборде. Все видят «Steve вышел из боя с Alex и погиб», а сам игрок при следующем входе
  узнаёт, почему умер.
- **Честно с киками.** `/kick` администратора, баны и рестарт не наказываются. Любой другой кик наказывается,
  так что чит не сможет выкинуть себя из боя кривым пакетом.
- **Инструменты администратора:** посмотреть, начать и закончить бой, список всех, кто сейчас в бою.
- **Плейсхолдеры PlaceholderAPI** и **события для разработчиков**: отменить попадание в бой, отреагировать
  на конец боя или простить выход.
- **Готов к Folia.** Каждый игрок обрабатывается в потоке, которому он принадлежит, а состояние боёв потокобезопасно.
- **Русский и английский** языки из коробки, любое сообщение можно изменить.

## Установка

1. Скачайте `FightClock-<версия>.jar` из [Releases](https://github.com/topdanya33200-netizen/FightClock/releases)
   и положите в `plugins/`.
2. Запустите сервер, затем отредактируйте `plugins/FightClock/config.yml`
   (для русского языка поставьте `language: ru`).
3. Выполните `/combat reload`.

Нужен Paper или Folia 26.1+ и Java 25. PlaceholderAPI необязателен.

## Команды

| Команда | Право | Что делает |
|---|---|---|
| `/combat` | `fightclock.status` (все) | Ваш таймер боя и противник |
| `/combat status <игрок>` | `fightclock.admin` | Бой другого игрока |
| `/combat list` | `fightclock.admin` | Все, кто сейчас в бою |
| `/combat tag <игрок> [секунды]` | `fightclock.admin` | Перевести игрока в режим боя |
| `/combat untag <игрок>` | `fightclock.admin` | Закончить бой игрока без наказания |
| `/combat reload` | `fightclock.admin` | Перезагрузить настройки и сообщения |

`/fightclock` работает как алиас.

| Право | По умолчанию | Значение |
|---|---|---|
| `fightclock.bypass` | ни у кого | Никогда не попадает в бой |
| `fightclock.bypass.commands` | ни у кого | Может использовать запрещённые команды в бою |

У операторов обхода по умолчанию нет, поэтому плагин работает одинаково, даже если проверять его с опкой.

## Настройка

Полный файл с комментариями создаётся при первом запуске. Что чаще всего меняют:

```yaml
combat:
  duration-seconds: 15        # каждый удар запускает отсчёт заново
  triggers: { melee: true, projectiles: true, explosions: true, potions: true }
  disabled-worlds: []

commands:
  mode: blacklist             # или whitelist
  list: [spawn, home, warp, back, tpa, tpaccept, rtp, ec, kit, hub]   # по умолчанию список длиннее

restrictions:
  blocked-teleports: [COMMAND, NETHER_PORTAL, END_PORTAL, END_GATEWAY]
  block-elytra: true
  disable-flight: true
  item-cooldowns: { ENDER_PEARL: 15, CHORUS_FRUIT: 10, ENCHANTED_GOLDEN_APPLE: 60 }

logout:
  kill: true
  safe-kick-causes: [KICKED, BANNED, IP_BANNED, WHITELIST, RESTART_COMMAND]
  commands: []                # например "tempban {player} 10m Вышел из боя"
```

## Плейсхолдеры

С PlaceholderAPI: `%fightclock_in_combat%` (`true`/`false`), `%fightclock_time_left%` (`12с`),
`%fightclock_seconds_left%` (`12`), `%fightclock_enemy%` и `%fightclock_fighters%` (сколько игроков сейчас в бою).
Значения берутся из памяти, так что скорборд может обновлять их хоть каждый тик.

## Для разработчиков

Три события, все вызываются в потоке, которому принадлежит игрок:

| Событие | Можно отменить | Когда |
|---|---|---|
| `CombatTagEvent` | да | Перед тем как игрок попадёт в бой или его таймер перезапустится. Длительность меняется через `setDuration`. |
| `CombatEndEvent` | нет | После конца боя: `EXPIRED`, `DEATH`, `LOGOUT` или `COMMAND`. |
| `CombatLogoutEvent` | да | Игрок выходит посреди боя. Отмена прощает выход, например чтобы заспавнить NPC. |

```java
@EventHandler
public void onTag(CombatTagEvent event) {
    if (event.getEnemy() != null && teams.sameTeam(event.getPlayer(), event.getEnemy())) {
        event.setCancelled(true); // союзники не дерутся
    }
}
```

## Сборка

```bash
./gradlew build       # jar плагина в build/libs/, заодно прогоняет юнит-тесты
./gradlew runServer   # запускает локальный тестовый сервер Paper 26.3 с плагином
```

Нужен JDK 25; если его нет, Gradle скачает его сам.

## Как устроен

```
src/main/java/.../fightclock
├── api/        события для других плагинов
├── combat/     учёт боёв, определение нападающего, таймер на экране, наказание, уведомления
├── command/    /combat (Brigadier) и правила запрета команд
├── config/     типизированный снимок конфига и языковые файлы MiniMessage
├── hook/       расширение PlaceholderAPI
├── listener/   слушатели урона, смерти, выхода и ограничений
└── util/       планировщик для Folia, форматирование времени
```

- **Потоки:** состояние боёв хранится в `ConcurrentHashMap` и меняется атомарными `compute`, поэтому читать его
  можно из любого потока. Всё, что касается игрока, выполняется в его планировщике; если удар пересекает границу
  регионов Folia, нападающий попадает в бой в потоке своего региона.
- **Наказание** — урон `generic_kill` от последнего противника: единственный тип урона, который не останавливает
  тотем, и при этом засчитывает убийство. Если другой плагин его заблокирует, здоровье игрока просто обнуляется.
  На Folia убийство засчитывается, только если противник в этот момент в том же регионе: так безопасно для потоков.
- **Юнит-тесты** (JUnit) проверяют учёт боёв, правила команд с алиасами и префиксами, разбор конфига, сообщения
  на обоих языках и ограничение повторных предупреждений.
- **Сквозной тест на настоящих серверах:** при каждом пуше GitHub Actions запускает Paper 26.1 и 26.3, и два бота
  дерутся друг с другом. Проверяются начало и конец боя, боссбар и таймер над хотбаром, запрет команд и телепорта,
  команды администратора, смерть за выход с сообщением и засчитанным убийством, уведомление при возвращении,
  прощённый кик и кулдаун эндер-жемчуга. Подробности в [`.github/server-test`](.github/server-test).
